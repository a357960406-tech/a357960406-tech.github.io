## 设计收敛

最初目标是开源、GitHub Pages 部署的单页介绍，先要求多轮澄清，随后明确转为“先做可预览页面”。主题收敛为图片素材与灵感探索，名称从 Dribbble 改成 Unsplash，以最终命名为准，不据此宣称官方身份。

设备范围为桌面端。参考分别涉及 Pinterest 图片探索、Lusion 空间与交互、Webflow 图片拖尾、KIKK 彩色拖尾、KPR 滚动翻转与景深。只参考点名部分，不应整站混合照搬。

风格最终围绕暗色背景、高清素材、绿色强调色与受控交互。人物剪影、积木打散、音效、厚玻璃卡片等曾被尝试或提出，不能当作现阶段必须保留的模块。

## 反馈如何转成方法

| 反馈或问题 | 可复用做法 |
| --- | --- |
| “不是片花，是图片形状变化” | 确认几何变化，区分单张曲面与整体蒙版 |
| 倾斜时穿模 | 外层负责命中坐标，表面负责 tilt；检查裁切与邻卡间距 |
| 大图模糊、主题违和 | 分开验证分辨率、放大态、纵深构图和产品主题 |
| 人脸被裁切 | 在实际卡片比例下调 object-position，不仅提高分辨率 |
| 五张素材后提前翻转 | 数量/筛选变化同步重算滚动长度、终点与转场时机 |
| 不要每屏都层叠 | 分别使用直接滚动、横向浏览、局部视差与翻转 |
| 音效后来取消 | 删除播放逻辑；曾提出不等于永久要求 |
| 另一浏览器仍未登录 | 识别认证通道，不让用户重复在错误浏览器登录 |
| 建仓库页面转圈 | 先确认仓库是否已创建，再续传，不重复建仓库 |
| 两套发布流程 | 统一来源与产物根目录，避免相互覆盖 |

## 当时验证证据

v31 检查过五张默认展示、建筑筛选、高清下载、最后卡翻转和滚动长度。首次发布通过连接器上传并更新远程分支；部署流程成功，浏览器确认样式及图片加载。刚读完 DOM 时曾见到未加载样式的布局，CSS 链加载后正常，所以不能凭首次快照判定失败。

这些是当时版本的结果。后续改动需要针对受影响部分重验，不把旧结果当作新版本通过。
