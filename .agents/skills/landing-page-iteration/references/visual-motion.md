# 素材与动效

用于图片质量、悬停、水波纹、拖尾、环绕画廊、滚动翻转与景深任务。下述方法按实际需求选择，不要求每页使用全部效果。

## 高清素材与裁切

- 同时判断分辨率、构图、主题与颜色。“更震撼”不等于更亮或更赛博，图片应解释产品内容。
- 获取真实可用的源文件并记录来源。用户指定图片时优先使用；要求不生成图片时使用现有或合法可用素材。
- 按预计显示宽度、设备像素比与放大幅度估算所需像素。缩略图和模糊背景不适合作为主展示图。
- 在最终比例下检查人脸、主体与前后景。优先调整 object-position；裁切无法保住主体时换素材或比例。
- 展示与下载分开：WebGL 纹理可限制尺寸节省显存，下载仍指向对应高清文件。
- 区分故意模糊的背景与应清晰的作品层。大蒙层不能用来遮掩低质素材。

## 动效分层

先定义触发事件、起止状态、方向、层级、停止/恢复条件与离开区块后的状态。

| 层 | 适合承担的变化 |
| --- | --- |
| 外层区块 | sticky、区块滚动与离场 |
| 卡片位置容器 | 横向位移、尺寸及翻转转场 |
| 卡片表面 | pointer tilt、悬停放大 |
| 图片内部 | 小幅视差、光影或景深 |
| 背景和装饰 | 独立速度的视差、水波纹与拖尾 |

避免多个动画重写同一 transform。使用嵌套层或组合 CSS 变量，并明确当前控制者。

### Tilt 与穿模

- 从不旋转的外层读取指针坐标，归一化到 -1…1；不要用正在旋转的表面反复计算 tilt，防止反馈抖动。
- 核对 perspective、transform-origin、preserve-3d 与正反面可见性，检查 overflow 和堆叠上下文。
- 悬停时提升当前卡片层级，按倾斜包络预留邻卡空间。间距变小后重新检查边缘互穿。
- 图片内部位移需要额外裁切余量，避免露边。用户取消厚度后，不用实体侧面和夸张阴影继续模拟厚度。
- 翻转接管期间减弱或关闭 tilt；完成、离开、筛选隐藏时复位。

### 环绕画廊

区分环绕布局与单张曲面。要求图片自身随弧线变形时，对每张卡片做曲面几何、网格或经过验证的近似，而不是用一个大弧形蒙版裁整排图片。

尺度、中心间距、曲率与深度共同决定可见间距。检查左右端、循环接缝与放大态；中心不重叠不代表边缘安全。

自动运动与悬停规则独立：是否全局暂停、放大哪张、离开如何恢复速度，以用户要求为准。命中区域跟随实际卡片，不能让大透明层挡住文案或按钮。

### 图片拖尾与水波纹

- 拖尾可按移动距离生成，限制同时存在数量与消失时间；避免逐帧创建大量 DOM。
- 文案与图片层级取自参考的实际状态。取消魔法棒或入场双图时，删除其触发与计时器，不只隐藏外观。
- 背景显影可组合模糊层、局部清晰揭示与水波纹；不要把整个页面随指针变亮。
- 静止指针是否仍有图片属于交互选择，不能擅自加默认示例或循环。

### 横向滚动、翻转与景深

用实际卡片宽度、间距、可见数量计算终点。翻转卡用稳定身份识别，不依赖筛选后最后一个 DOM 元素恰好是原翻转卡。

进度拆成可检查阶段，例如：横向浏览 → 最后卡停位 → 翻转换图 → 扩展画幅 → 拉远 → 俯视。阶段可重叠，但不能横向未完成就提前放大。终态需自然衔接下一区块。

隐藏翻转卡时，正常结束浏览或进入定义好的替代状态；不对不存在的卡继续推进相机。测试全部、单卡、空态、重置与中途筛选。

近远感需要前后景的不同尺度/位移。普通 scale 是平面缩放；单张图高度图/景深属于近似，不声称真实三维场景。检查前景拉伸、空洞、露边与纹理清晰度，优先选本身有纵深的构图。

### 滚动模式与性能

区分 scroll scrub、进入播放一次与循环播放。要求“一次、不循环”时不添加无限闪烁；进度跟随滚动的效果应保持可解释的前后状态。

连续更新使用 requestAnimationFrame、transform/CSS 变量或图形层，减少每帧布局读取和大树重渲染。尺寸在布局变化时重测；空闲、离屏和标签隐藏时停止不必要绘制。大图加载失败、WebGL 不可用或减少动态效果时仍能浏览内容。

## 验证证据

同视口观察起点、中间态与终点，不能只看首屏截图。悬停检查中心和四角；转场检查正面、侧面与背面；图片检查正常与最大放大态。只报告实际完成的验证。
