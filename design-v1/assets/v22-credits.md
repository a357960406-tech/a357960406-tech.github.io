# Dribbble 第二十二版

图片、字体与画面沿用第二十一版，素材来源见 v20-credits.md。没有生成新图片。

翻转音效改为本地 Web Audio 合成的 0.40 秒触觉音效，没有外部采样依赖：

- 0–0.30 秒：轻薄、弱音量的中高频气流，850Hz 高通消除低频噪声，6200Hz 低通控制刺耳感；声像沿翻转方向轻微移动。
- 0.30–0.40 秒：短促正弦低频触点，158Hz 快速下落到 82Hz，4ms 起音、95ms 内衰减，保持干净实体反馈。
- 不添加混响、回声或持续尾音。原先独立的全屏双音收束移除，落定反馈合并到翻转音效中。

音效默认关闭，使用右侧按钮启用。悬停轻音、静音、页面隐藏暂停与滚动防重复触发逻辑保留。
